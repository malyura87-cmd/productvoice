# ТЗ: ProductVoice — AI-відеоопис товару

> Як користуватися: поклади цей файл у корінь репозиторію як `TZ.md`.
> У Claude Code пиши по одному етапу: «Прочитай TZ.md і виконай Етап 1». Після кожного етапу перевір живе посилання на Vercel і тільки тоді переходь до наступного.

## Що робимо

Веб-сервіс: користувач вводить назву товару (і, за бажанням, опис або посилання) та завантажує фото.
Сервіс генерує:
1. короткий рекламний сценарій 20–30 секунд (Gemini);
2. озвучку сценарію (ElevenLabs);
3. вертикальне прев'ю 9:16: фото + субтитри, синхронні з озвучкою;
4. (бонус) експорт у MP4.

Мова інтерфейсу і сценаріїв — українська.

## Стек

- Next.js (App Router) + TypeScript + Tailwind CSS
- Деплой: Vercel (автодеплой з GitHub, гілка `main`)
- Gemini API — офіційний SDK `@google/genai`
- ElevenLabs API — REST
- Ключі тільки на сервері (API routes), у браузер не потрапляють

## Змінні середовища

Задаються у Vercel → Settings → Environment Variables і локально в `.env.local` (файл у `.gitignore`).

| Змінна | Що це |
|---|---|
| `GEMINI_API_KEY` | ключ з Google AI Studio |
| `GEMINI_MODEL` | назва Flash-моделі, актуальна в AI Studio на момент розробки |
| `ELEVENLABS_API_KEY` | ключ ElevenLabs |
| `ELEVENLABS_VOICE_IDS` | 2–3 id голосів через кому (жіночий, чоловічий) |
| `DAILY_LIMIT` | ліміт генерацій на день з одного IP, за замовчуванням 3 |

Додай `.env.example` з цими назвами без значень.

**Зробити**

## Етап 2. Сценарій через Gemini

**Зробити**
- `POST /api/script` приймає `{ name, description }`, повертає JSON:
  ```json
  { "hook": "…", "body": "…", "cta": "…" }
  ```
- Використати structured output (JSON-схема відповіді), щоб відповідь завжди парсилась.
- Промпт (системна інструкція):
  ```
  Ти — копірайтер коротких відео для інтернет-магазину.
  Напиши сценарій озвучки на 20–30 секунд (60–80 слів) українською.
  Структура:
  - hook: одне речення про проблему або бажання покупця;
  - body: як саме цей товар вирішує проблему, 2–3 конкретні переваги;
  - cta: короткий заклик до дії.
  Пиши живо, без канцеляризмів і без вигаданих характеристик —
  тільки те, що випливає з назви й опису.
  ```
- На фронті: після «Згенерувати» індикатор «Пишу сценарій…», далі три блоки (Hook / Основне / Заклик), кожен можна редагувати вручну.
- Кнопка «Інший варіант» — повторна генерація.
- Помилки: зрозуміле повідомлення українською, без технічних деталей.

**Готово, коли**
- На живому сайті за назвою товару з'являється сценарій, його можна редагувати й перегенерувати.

## Етап 3. Озвучка через ElevenLabs

**Зробити**
- `POST /api/voice` приймає `{ text, voiceId }`, де `text` = hook + body + cta.
- Використати ендпоінт Text to Speech **with timestamps**, щоб отримати аудіо і таймінги символів (для субтитрів на етапі 4). Модель — багатомовна, з підтримкою української.
- Повертати на фронт: аудіо (base64 або blob) + масив таймінгів.
- Вибір голосу на фронті: 2–3 кнопки з `ELEVENLABS_VOICE_IDS`, підписи «Жіночий» / «Чоловічий».
- Плеєр аудіо + кнопка «Завантажити mp3».
- Внизу сторінки підпис «Voice by ElevenLabs» (вимога безкоштовного плану).

**Готово, коли**
- Відредагований сценарій озвучується вибраним голосом, mp3 відтворюється і завантажується.

## Етап 4. Прев'ю 9:16 із субтитрами

**Зробити**
- Компонент `Preview`: вертикальна рамка 9:16, фото товару на весь кадр (object-fit: cover), легке повільне наближення (Ken Burns).
- Субтитри внизу кадру великим жирним шрифтом з тінню, по 3–6 слів, змінюються синхронно з аудіо за таймінгами з етапу 3.
- Кнопка Play/Pause поверх кадру.
- Блок «Як це зроблено» під прев'ю: Gemini → ElevenLabs → прев'ю (одна строка зі стрілками).

**Готово, коли**
- Натискаю Play — бачу фото, чую озвучку, субтитри йдуть точно під голос.

## Етап 5 (бонус). Експорт MP4

- Кнопка «Завантажити відео»: склеїти в браузері фото + анімацію + субтитри + аудіо у вертикальне MP4 1080×1920 (ffmpeg.wasm або canvas + MediaRecorder — обери простіший варіант, який стабільно працює в Chrome).
- Індикатор прогресу рендеру.

**Готово, коли**
- Файл MP4 відкривається на телефоні, звук і субтитри синхронні.

## Етап 6. Захист і полірування

- **Ліміт:** не більше `DAILY_LIMIT` генерацій сценарію й озвучки на день з одного IP. Для зберігання лічильника — Upstash Redis (безкоштовно, підключається через Vercel Marketplace). Якщо Redis не налаштований — ліміт вимикається, але сайт працює. При перевищенні: «Демо-ліміт на сьогодні вичерпано, спробуйте завтра».
- **Валідація:** назва 2–120 символів, опис до 1000 символів, сценарій для озвучки до 600 символів.
- **Демо-приклад:** кнопка «Спробувати на прикладі» підставляє готовий товар (наприклад, шампунь для блиску волосся) з фото з `public/`.
- **SEO/шеринг:** title, description, Open Graph-картинка, favicon.
- **README.md:** що робить, посилання на демо, GIF або скриншоти, схема, стек, як запустити локально, розділ «Як зроблено» (Claude Code, скільки днів).

**Готово, коли**
- Ключі не видно ні в браузері, ні в GitHub; ліміт працює; README зрозумілий людині, яка бачить проєкт уперше.
